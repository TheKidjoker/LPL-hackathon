# Fraud Speed Bump

LPL Financial Hackathon project. When a risky withdrawal comes in, the system pauses it, has Claude explain
why it looks like a scam, and alerts the client, their advisor, and LPL's fraud team at once.

Rules, deadlines, deliverables, and the plan are in [docs/HACKATHON_CONTEXT.md](docs/HACKATHON_CONTEXT.md).

**Deadline: Saturday 12:00 PM ET** (deck, code ZIP, submission form).
